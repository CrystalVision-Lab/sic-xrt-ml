# 위치 안정성과 관찰 범위 재학습

방향에 따라 예측이 달라지는 개발 표본을 진단하고, 위치 변화 학습과 중심 영역 확대를
독립적으로 비교합니다. 기존 제공자 라벨·좌표·데이터 분할을 수정하지 않습니다.

## 진단과 실험 설계

8,962개 개발 표본에서 중심 신호 대 주변 잡음, 국소 고대비 특징의 중심 거리,
기록된 다른 종류 ROI의 존재를 계산합니다. 불안정 455개와 나머지 표본을 비교하고
대표 이미지를 살펴봅니다. 이 값은 원인 후보이지 결함 위치나 유형의 전문가 정답이
아닙니다. 같은 표본이 여러 후보에 해당할 수 있으며, 설명되지 않는 사례도 남깁니다.

`training.spatial_robustness.run_comparison`은 다음 설정을 실험 전에 저장합니다.

| 항목 | 고정 설정 |
| --- | --- |
| 개발 자료 | 기존 cohort v1, W1·W2·W9, W8 금지 |
| 설정 A | 중심32+주변128, 학습 중 ±4px 정수 이동 |
| 설정 B | 중심64 원해상도+주변128, 이동 없음 |
| 공통 학습 | 명암 보정, sampling power 0.75, seed 42/43, 12 epoch |
| 증강 | 기존 회전·반전·명암 증강, A에만 반사 패딩 이동 추가 |
| 분할 | 웨이퍼 전체를 번갈아 보류, 열처리 전후도 동일 그룹 |
| 모델 선택 | 마지막 epoch 고정, 보류 점으로 epoch 선택 금지 |
| 추론 비교 | 두 seed 확률 평균의 원본 방향 및 C4 |

중심64는 원해상도 64×64를 읽고 기존과 같은 크기의 특징으로 모읍니다. 중심32와
학습 파라미터 수는 같습니다. 주변128은 기존과 같이 2배 평균 축소합니다.
이동 증강은 픽셀 보간이나 wrap 없이 반사 패딩 후 정수 위치를 선택합니다.
검증에는 이동·명암 증강을 적용하지 않습니다. 원본 좌표를 보정하는 기능이 아닙니다.

진단한 보류 표본을 학습에 넣거나 특별 가중하지 않습니다. 각 폴드의 학습 표본은
다른 웨이퍼 전체이며, sampler의 빈도도 학습 자료만으로 계산합니다. 진단을 바탕으로
전역 설정을 선택한 적응적 개발이므로 결과를 새로운 독립 시험 성능으로 해석하면 안 됩니다.

## 채택과 산출물

기준은 기존 두 seed 모델의 원본 방향 추론입니다. 모든 웨이퍼의 BPD TP 비감소,
FP 비증가, W1 FP 엄격 감소, 합친 OOF Macro F1 비감소 조건을 모두 충족해야 합니다.
통과 후보는 W1 FP 최소, 전체 FP 최소, Macro F1 최대, 추론 방향 수 최소 순으로 고릅니다.
기존 C4도 동일 표에 남깁니다. 아무 후보도 통과하지 못하면 기존 모델을 유지합니다.
각 후보의 탈락 사유와 학습·추론 시간을 기록하며, 결과를 보고 조건을 바꾸지 않습니다.

새 후보가 선택되면 같은 설정으로 전체 개발 자료에서 두 seed를 재학습합니다.
저장 후 다시 읽어 예측 확률이 같은지 확인합니다. 선택되지 않은 폴드 모델은 연구
비교 기록으로만 남깁니다. 서버의 운영 모델이나 W8 시험을 자동 변경하지 않습니다.

## 모델 계약

- 체크포인트: `NormalizedSpatialCNN_v1`, 정확한 전처리·중심 크기·이동 설정을 기록.
- 전체 개발 후보 포인터: `spatial_research_candidate` v1, 구성 모델 경로/SHA256,
  seed42/43, manifest, 동일 가중치, 원본/C4 추론 모드를 고정.
- 로더: `load_spatial_candidate`는 해시·클래스·전처리·학습 설정·seed·epoch·전체 학습
  웨이퍼를 검사합니다. 보류 폴드 모델을 최종 후보로 쓰는 것을 거부합니다.
- 입력: 표시 없는 RGB128 원본을 float32 NCHW/255로 변환. 명암 보정은 모델 내부.
- 출력: 평균 확률의 로그. `softmax(1)`로 세 클래스 BPD/TED/TSD 확률을 얻습니다.

기존 모델 로더와 데이터 계약은 변경하지 않습니다. TED a~f 같은 방향 세부형에는
이 회전·반전 증강과 C4 평균을 그대로 적용할 수 없습니다. 모든 실제 데이터, 진단
사례, 예측, 모델은 로컬에 저장하며 Git에는 코드·테스트·계약 문서만 올립니다.
