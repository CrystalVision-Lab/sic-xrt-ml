# BPD 소수 클래스와 문맥 입력 비교

## 문제와 고정 조건

좌표 보정 데이터셋에서 기존 최고 모델은 BPD 20/33, 전체 Macro F1 0.882053이다. BPD 검증 패치 33개는 원본 TIFF의 해당 좌표에서 정확히 추출되었음을 확인했다. 13개 불일치 사례에서 중심 32픽셀 밖으로 선 형태가 이어지는 모습이 관찰되었다. 이는 문맥 입력을 시험하는 근거이며 타입 라벨 변경 근거로 사용하지 않았다.

학습 7,123개 중 BPD는 146개다. 학습/검증 CSV, 보정 좌표, 클래스, 검증360개와 시험 웨이퍼는 고정한다. 이미 여러 실험에서 사용한 검증 웨이퍼이므로 결과는 탐색용이며 독립 일반화 성능이 아니다.

## 사전에 정한 비교

- 중심32 대조군: 기존 SmallPatchCNN 구조에 학습용 클래스 균등 샘플링과 증강을 적용한다.
- 중심32+문맥128: 원래128픽셀 패치에서 중심32를 보고, 전체128을 평균 풀링으로64로 축소한 별도 가지의 특징을 결합한다. 주변 결함만으로 분류하지 않도록 중심 입력을 함께 유지한다.
- 각 후보는 seed42, 15epoch, batch32, AdamW learning rate0.001로 비교한다. 가장 높은 Macro F1 후보가 기존 모델보다 전체F1과 BPD재현율 모두 개선되면 seed43으로 한 번 추가 확인한다. 무제한 탐색하지 않는다.

샘플별 가중치는 학습 클래스 개수의 역수이고, 원래 학습 표본 수만큼 복원 추출한다. 손실은 무가중 교차 엔트로피다. 역빈도 손실까지 중복 적용하지 않는다. 증강은 학습에만 적용한다: 90도 단위 회전과 좌우 반전, 대비0.8~1.2, 밝기±0.04. 방향별 세부 타입은 학습하지 않는다. 검증은 원본 픽셀 그대로 결정적으로 처리한다.

## 모델과 산출물 계약

기존 데이터셋 schema-v1은 변경하지 않는다. 출력 plan/comparison JSON schema_version=1과 `BPDContextCNN_v1` 체크포인트를 별도 경로에 저장한다. 체크포인트는 `bpd_context.load_model`로만 읽으며, 모델 이름·전처리 문자열·variant·클래스 순서를 확인한다. 기존 `SmallPatchCNN_v1_from_scratch` 체크포인트와 호환된다고 가정하지 않는다.

입력은 표식 없는 원본128×128 RGB이며 uint8/uint16을 해당 자료형 최댓값으로 정규화한다. 중심 자르기와 문맥 평균 풀링은 모델 안에서 수행한다. 평가 시 회전/밝기 증강은 사용하지 않는다. 클래스 순서는 BPD, TED, TSD다.

입력 파일은 캐시 적재 때 SHA로 검증하고 읽기 전용 스냅샷으로 보관한다. 시험 패치를 캐시에 넣으면 거절한다. 학습이 끝나면 모델을 다시 로드해 혼동행렬이 저장된 평가와 일치하는지 검사한다. 비교 종료 시 데이터 manifest와 기존 모델 SHA가 유지되는지도 검사한다. 실제 자료·예측·모델은 Git에 넣지 않는다.

성능 판단에서는 BPD 정답 개수뿐 아니라 BPD 오탐, TED/TSD 성능, 전체 Macro F1과 정확도를 함께 보고한다. 추가 초기값 확인은 동일 검증셋에서의 반복 실험이므로 독립 시험을 대체하지 않는다.

## 로컬 GPU 결과 및 추가 평균 예측

| 방식 | Macro F1 | 정확도 | BPD 정답 | 다른 타입을 BPD로 오탐 |
|---|---:|---:|---:|---:|
| 기존 모델 | 0.882053 | 94.72% | 20/33 | 4 |
| 균등 샘플링·증강, 중심32, seed42 | 0.906918 | 94.44% | 31/33 | 16 |
| 중심32+문맥128, seed42 | 0.906848 | 95.83% | 23/33 | 4 |
| 중심32, 확인 seed43 | 0.899700 | 95.56% | 21/33 | 3 |
| 중심32 두 초기값의 50:50 평균 | 0.942021 | 97.22% | 26/33 | 2 |

두 초기값에서 전체 Macro F1은 개선됐으나 BPD 정답 수 차이가 컸다. 이를 확인한 후 확률을 같은 비율로 평균하는 한 가지 추가 실험을 계획에 기록했다. 평균 비율을 검증 점수로 탐색하지 않았다. 평균 예측 결과는 BPD26/33, TED254/257, TSD70/70이었다. 이 추가 방식도 같은 검증셋을 보고 제안한 탐색이므로 독립 시험 결과는 아니다.

`average_predictions`는 point ID·클래스·표본 순서·확률 범위를 검사한 뒤 평균한다. `load_ensemble`은 `equal_probability_seed_ensemble` schema-v1 계약의 고정 균등 가중치, 서로 다른 체크포인트 SHA와 학습 manifest 일치를 검증한다. 반환 모델은 평균 확률의 로그를 출력하므로 일반적인 softmax/argmax 추론과 함께 사용할 수 있다. 두 모델을 실행하므로 단일 모델보다 추론 연산량이 늘어난다.

연구 모델 사용 예:

```python
from sic_xrt_ml.training.bpd_context import load_ensemble

model = load_ensemble(".../ensemble_plan.json", device="cuda")
# inputs: 표식 없는 원본128픽셀 RGB, 자료형 최댓값으로 정규화한 NCHW tensor
probabilities = model(inputs).softmax(1)
```

이 모듈은 기존 학습 서버 모델 파일을 덮어쓰지 않는다. 데이터 원본/타입 라벨/시험셋도 변경하지 않는다. 결과의 품질 개선은 모델의 제공자 라벨 일치도 향상이며 전문가 정답 확정과 구분한다.
