# 중심 대비 입력과 추가 배경의 비교 실험

`python -m sic_xrt_ml.training.center_background --cohort ... --background ... --baseline ... --observations ... --added ... --frozen ... --output 새폴더`

## 목적 및 범위

기존 독립 배경 판별기가 제외 웨이퍼에서 배경과 제공 결함을 구분하지 못한 문제를 대상으로 한다. 기존 세 종류 분류 모델과 UI는 변경하지 않는다. 새 분류 모델의 종류 정확도를 평가하는 실험이 아니다.

원본 대비 입력/중심 대비 입력 × 기존 배경/추가 배경의 네 조건을 같은 개발 웨이퍼 1·2·9, 시드, 16에포크, 최종 에포크 모델로 비교한다. 한 웨이퍼의 모든 자료를 학습에서 제외한 뒤 평가한다. 최종 시험 웨이퍼 8은 로더에서 거부한다. 개발 자료를 반복 사용한 탐색 실험이므로 최종 일반화 성능으로 보고하지 않는다.

## 입력과 통제

- 기존 `IndependentBackgroundCNN`의 두 분기와 학습 파라미터 수는 유지한다.
- 새 입력은 RGB 평균의 9px·31px 국소 평균을 빼고, 중심에서 32~60px 떨어진 고리의 중앙절대편차로 대비를 정규화한다. 낮은 대비에서 1/255 하한을 사용한다.
- 중심 48px를 64px로 보간하고, 주변 영상은 중심에서 멀어질수록 가중치를 줄여 64px로 축소한다. 입력 채널은 두 크기의 부호 있는 대비와 작은 크기 대비의 절댓값이다. 원래 밝기·색은 직접 공급하지 않는다.
- 모든 조건은 같은 AdamW, 회전·반전·밝기 보강 및 웨이퍼별 같은 샘플 수를 사용한다. 추가 배경은 기존 일반 배경 그룹의 샘플링 비중을 공유한다.
- 동일한 전용 난수 생성기로 대조군도 다시 학습한다. 이전 체크포인트는 별도 참고 결과로만 사용하며, 입력 해시와 기존 예측 재현을 검증한다. 최고 평가 점수 에포크 선택·평가 임계값 튜닝을 하지 않는다.

## 자료 계약

추가 파일은 DataTools가 생성하는 `xrt_weak_background_v1` 계약이다. 코호트·좌표 보정 해시, 패치 해시·크기, 고유 ID, 기존 자료와의 중복 패치 해시, 웨이퍼, AI 약지도 출처를 검사한다. `uncertain`·`artifact_candidate`는 학습에서 제외한다. 추가 자료의 검토 결과는 고정하고 학습 결과를 보고 재라벨링하지 않는다.

모든 조건은 동일한 기존 양성·기존 배경·추가 배경·불확실 도전 자료로 평가한다. 추가 자료를 사용하지 않는 조건도 동일한 추가 평가 자료를 받는다. 추가 자료를 사용하는 조건 역시 제외 웨이퍼의 추가 자료를 학습하지 않는다.

새 체크포인트는 연구용 PyTorch 파라미터이며 계약은 `center_background_v1_rgb128_uint8_mad_box9_31_center48_gaussian_context`다. 기존 ONNX 모델의 대체 파일이 아니다. 입력 파일·계획 해시 및 각 조건의 전체 예측을 저장한다.

## 판정

배경 점수 0.95, 결함 점수 0.8을 고정한다. 제공 양성 전체 99%·각 종류 98%·결함 가능성 도전 자료 98%를 보존하면서, 지원되는 기존 및 추가 배경 그룹별 70% 이상을 제거해야 한다. 알려진 종류의 예측은 수정하지 않는다.

숫자 통과 외에도 실제 검출 후보의 배경 자료가 2개 이상 웨이퍼에서 뒷받침되어야 하며, 전체 이미지의 결함 보존 검증이 필요하다. 실행기는 항상 `not_promoted`로 끝나고 내보내기·프로그램 교체를 수행하지 않는다. 배경은 AI 약지도이므로 전문가 확정 정답에 대한 정확도라고 표현하지 않는다.

## 검증

밝기·이득 변경에 대한 입력 안정성, 먼 모서리 물체에 대한 중심 입력 독립성, 일정 영상의 유한한 출력·기울기, 동일 학습 파라미터 수, 웨이퍼 및 불확실 자료 분리, 추가 자료 중복·출처 오류 거부를 테스트한다.
