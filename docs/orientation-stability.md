# 방향별 예측 안정성과 BPD 오탐

현재 BPD 후보의 개발 오탐이 특정 웨이퍼에 집중되는 문제를 조사합니다.
`training.orientation_stability.run_comparison(root, previous, output)`은 기존 두 seed
모델을 고정하고 identity, C4, D4의 확률 평균만 비교합니다. 추가 학습은 하지 않습니다.

## 고정 실험과 선택 조건

- 입력은 기존 `wafer_grouped_development_cohort` v1의 W1·W2·W9입니다. W8은 읽지 않습니다.
- 각 웨이퍼는 해당 웨이퍼를 학습에서 제외한 기존 두 모델로만 추론합니다.
- 모델 해시, manifest, 학습/보류 웨이퍼, 학습 회수, 전처리 계약을 검사합니다.
- 원본 방향의 OOF를 다시 계산하여 이전 기록의 예측과 확률이 재현되는지 확인합니다.
- C4는 0·90·180·270도, D4는 그 네 방향과 각 방향의 좌우 반전입니다.
  정수 회전/반전이므로 보간이나 원본 파일 수정 없이 동일 픽셀을 재배열합니다.
- 각 방향에서 두 모델의 확률을 평균한 뒤 방향별 확률을 동일 가중치로 평균합니다.
  logits를 평균하지 않습니다. 설정과 선택 조건은 추론 전 `plan.json`에 기록합니다.
- 모든 웨이퍼의 BPD TP가 기준 이상, FP가 기준 이하이고 W1 FP는 엄격히 감소해야 합니다.
  합친 OOF Macro F1도 기준 이상이어야 합니다. 통과 후보는 W1 FP 최소, 전체 FP 최소,
  Macro F1 최대, 방향 수 최소 순서로 고릅니다. 통과 후보가 없으면 기존 추론을 유지합니다.

이 조건은 전체 지표 상승이 일부 웨이퍼의 악화를 가리지 않도록 합니다.
방향별 불일치는 예측 불안정성의 지표이며 라벨 오류의 증거가 아닙니다.
라벨을 자동으로 바꾸거나 불일치 표본을 평가에서 제외하지 않습니다.

학습에 이미 사용한 회전·반전 증강을 추론에도 적용하는 실험이며 TED/TSD/BPD의
**기본 종류 분류에만** 해당합니다. TED a~f처럼 방향이 의미를 가지는 세부 라벨에는
그대로 사용할 수 없습니다. 실제 결정학적 대칭이나 라벨 정확성을 입증하지 않습니다.

## 저장 및 로더

`orientation_mean_research_candidate` v1 포인터에는 이전 후보 포인터 경로·SHA256,
개발 manifest, 클래스 순서, 전처리, 변환 순서, 방향 수·평균 가중치를 기록합니다.
`load_orientation_candidate(pointer, device)`는 이 계약과 부모 포인터 해시를 검증한 뒤
기존 엄격한 `load_candidate`로 구성 모델을 읽습니다. 부분 학습 폴드 모델을 전체
개발 후보 대신 사용할 수 없습니다. `softmax(1)`을 적용하면 평균 확률을 얻습니다.

입력은 표시가 없는 원본 RGB128 패치를 float32 NCHW/255로 변환한 값입니다.
명암 보정은 모델 안에서 수행합니다. 호출자가 다시 보정하지 않습니다.
선택 후 저장 포인터를 다시 읽어 동일한 개발 입력의 예측 확률이 일치하는지 확인합니다.

방향별 예측·불일치, 3가지 OOF, 혼동행렬과 웨이퍼별 추론 시간은 로컬에 저장합니다.
동일 배치에서 측정한 시간은 참고치이며 별도 장비 벤치마크가 아닙니다. C4/D4는
기존 두 모델 추론을 각각 4/8회 수행하므로 추가 처리 비용을 결과와 함께 고려해야 합니다.

평가 자료는 설정 선택에 사용한 개발 OOF입니다. 독립 시험 결과가 아니며 서버 모델을
자동으로 교체하지 않습니다. 원본 영상·라벨·모델·예측은 Git에 포함하지 않습니다.
