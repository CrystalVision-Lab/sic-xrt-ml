# 좌표 보정 전후 성능 비교

DataTools의 `explicit_horizontal_mirror_coordinate_repair` schema-v1 계약을 소비한다. 다른 저장소 코드를 가져오거나 원본 이미지를 직접 보정하지 않는다. 기존 schema-v1 데이터셋 로더는 그대로 사용하며, 두 manifest 사이의 차이는 명시된 검증 패치의 좌표 보정 기록과 정확히 일치해야 한다. train/test, 클래스, point ID, 웨이퍼, 세부 타입이 달라지면 비교를 거절한다.

`training.coordinate_repair_comparison.compare_repair`는 다음을 분리한다.

1. 기존 모델의 동일 체크포인트로 기존 입력과 보정 입력을 각각 평가한다. 여기서의 점수 변화는 입력 데이터 오류 수정 효과다.
2. 학습 표본과 하이퍼파라미터를 유지해 재학습하고 보정된 검증셋으로 체크포인트를 선택한다. 학습 자료가 같더라도 CUDA 비결정성과 선택 기준 변화로 결과가 달라질 수 있다.

결과는 체크포인트 SHA, 두 manifest SHA, 보정 계약 SHA, 종류별 점수와 혼동행렬을 보존한다. 시험셋은 사용하지 않는다. 동일 검증 웨이퍼를 반복 이용한 탐색 결과이며 독립 일반화 성능을 주장하지 않는다. 기존 품질 필터가 잘못된 좌표에서 적용되었다는 선택 편향도 남는다.

계약 검증 및 학습 실패 시 FAILED.json을 남긴다. 실제 데이터, 예측, 모델은 Git에 포함하지 않는다.

## 로컬 RTX 3050 비교 결과

학습 7,123개, 검증 360개를 유지했다. 보정 대상은 검증 TSD 70개이며 타입 라벨은 그대로다. AdamW, 15 epoch, batch 32, learning rate 0.001, seed 42, 역빈도 가중 손실을 유지했다.

| 모델 | 기존 입력 Macro F1 | 보정 입력 Macro F1 | 보정 입력 정확도 |
|---|---:|---:|---:|
| 기존 128픽셀 | 0.437805 | 0.719364 | 0.861111 |
| 기존 64픽셀 | 0.506727 | 0.812367 | 0.919444 |
| 기존 32픽셀 | 0.523760 | 0.830234 | 0.936111 |
| 재학습 128픽셀 | 해당 없음 | 0.727103 | 0.886111 |
| 재학습 32픽셀 | 해당 없음 | 0.882053 | 0.947222 |

최고 후보는 재학습 32픽셀의 epoch 15다. BPD 20/33, TED 251/257, TSD 70/70을 맞혔다. 특히 BPD 재현율 60.6%는 여전히 개선이 필요하다. 이전 32픽셀 모델의 TSD 8/70→70/70 변화는 정확한 원본 좌표 보정 효과이며, 타입 라벨 재작성이나 학습 자체의 향상으로 보고하지 않는다.
