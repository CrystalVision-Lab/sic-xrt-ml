# 고정 모델의 1회 예약 웨이퍼 시험

`training.final_test.evaluate_frozen_ensemble`는 예약된 한 웨이퍼의 전체 시험 코호트를
고정된 동일 가중치 앙상블로 평가한다. Data Tools `pretest_source_audit` v1의 manifest,
첨부 파일 해시, 학습 점검 수와 연구 평가 가능 상태를 검증한다. 저장소 간 코드 import는 없다.

평가 전 모델 파일, 원본 데이터셋의 보호 해시와 모든 입력 형태를 확인한다. 코호트,
모델/감사 해시, 전처리, 가중치, argmax 규칙을 `frozen_plan.json`으로 먼저 기록한다.
데이터셋 상위의 `final_test_ledger/<cohort SHA256>.json`은 배타적으로 생성되며, 출력
폴더를 바꿔도 같은 코호트를 이 평가기로 다시 실행할 수 없다. 실패 후에도 기록을
남긴다. 이 로컬 방어는 다른 도구나 수동 파일 삭제까지 막는 보안 장치는 아니다.

추론은 augmentation/학습/추가 모델 선택 없이 한 번 실행한다. `test_predictions.json`,
`test_result.json`과 완료 영수증을 저장한다. 기존 데이터셋의 `test_evaluated:false`는
생성 시점의 메타데이터로 보존하고, 평가 여부는 이 시험 기록을 기준으로 판단한다.

이번 로컬 연구 시험: 학습 W1/9, 반복 튜닝 검증 W2, 최초 예약 시험 W8.
고정 모델은 center32 seed 42/43의 같은 가중치 앙상블이다. 1,295개 전체를 평가했다.

| 지표 | 반복 사용 검증 W2 | 최초 시험 W8 |
|---|---:|---:|
| 표본 수 | 360 | 1,295 |
| 정확도 | 97.22% | 95.83% |
| Macro F1 | 0.9420 | 0.6976 |
| BPD 정답/전체 BPD | 26/33 | 4/6 |
| TED→BPD | 2 | 52 |

시험 혼동행렬은 실제 행/예측 열, BPD/TED/TSD 순서로
`[[4,1,1],[52,728,0],[0,0,509]]`이다. BPD 예측 56개 중 맞는 것은 4개이므로
정밀도는 7.14%이다. 전체 정확도만으로 BPD 성능이 좋다고 해석하면 안 된다.
시험 BPD는 6개뿐이며 패치들은 한 웨이퍼에 속하므로 많은 독립 표본으로 간주할 수 없다.

이는 전문가 확정 라벨이 아닌 제공자 ROI 파일명·AI 선별 연구 라벨과의 일치도다.
깨끗한 선별 코호트의 3종 중심 패치 분류이며, 전체 웨이퍼 자동 검출, a~f 세부 유형,
애널링 전후 추적, 길이/각도/깊이 측정 성능은 평가하지 않았다.

시험 결과를 본 이후 모델·임계값·라벨을 재선택하지 않았다. 향후 개선에 W8의 결과를
활용하면 W8은 개발 자료가 되며, 별도의 새로운 독립 시험 자료가 필요하다.
