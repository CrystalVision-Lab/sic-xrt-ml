# BPD 누락 개선: 오탐 제한 개발 실험

명암 보정 중심+주변 모델이 BPD 오탐을 줄였지만 일부 BPD를 놓칩니다.
`training.recall_budget.run_comparison(root, previous, output)`은 기존 교차검증을 보존하고
동일한 개발 표본에서 반복 학습 안정성과 희소 클래스 학습 비중을 비교합니다.

## 실험 계약

- Data Tools `wafer_grouped_development_cohort` v1을 읽기 전용으로 사용합니다.
- 개발 웨이퍼는 1·2·9이며 웨이퍼 8은 입력 단계에서 거부합니다.
- 각 웨이퍼의 열처리 전후와 모든 패치를 함께 보류합니다. 나머지 웨이퍼로만 학습합니다.
- 기존 명암 보정 중심32+주변128, sampling power 0.5, seed 42를 기준으로 사용합니다.
  이전 결과·예측·모델 해시, 표본 식별자, 폴드별 학습 웨이퍼를 확인합니다.
- 새 실험은 power 0.5/seed 43, power 0.75/seed 42, power 0.75/seed 43입니다.
- 12 epoch의 마지막 모델을 사용합니다. 보류 자료로 epoch를 선택하지 않습니다.
- 같은 power의 두 seed 예측 확률을 1:1 평균한 앙상블 두 개도 비교합니다.
- 모든 설정, 앙상블, 오탐 제한, 선택 규칙을 첫 학습 전 `plan.json`에 저장합니다.

세 웨이퍼의 보류 예측을 모아 동일 표본에 대한 BPD TP/FN/FP와 Macro F1을 계산합니다.
BPD 오탐이 기존보다 많지 않고 Macro F1이 기존 이상인 후보 중 BPD 재현율이
**엄격히 개선된** 후보만 선택합니다. 재현율 동률이면 Macro F1, 구성 모델 수 순으로
선택합니다. 개선 후보가 없으면 기존 모델을 유지합니다.

이는 반복 개발과 설정 선택에 사용한 OOF 결과입니다. 독립 시험 성능이나 전문가
정답 검증을 뜻하지 않습니다. BPD는 두 웨이퍼에만 있고 W9에는 없으므로 W9의 BPD
재현율은 해석하지 않습니다. 두 seed만으로 통계적 안정성을 확정할 수 없습니다.
점 중심 패치의 거친 유형 분류이며 전체 영상 검출, 세부 a~f, 전후 추적과는 다릅니다.

## 후보 모델과 호환성

`candidate.json`의 `normalized_recall_budget_candidate` v1 계약은 기존 원본 입력
앙상블 계약과 구별됩니다. 클래스 순서는 BPD/TED/TSD, 입력은 표시가 없는 RGB
128×128 uint8 패치를 float32 NCHW/255로 변환한 값입니다. 명암 보정은 모델 내부에
포함되므로 호출자가 중복 적용하면 안 됩니다. 입력 좌표나 원본 라벨은 변경하지 않습니다.

`load_candidate(pointer, device)`는 구성 모델 SHA256, 전처리, 클래스, 개발 manifest,
seed·학습 설정·epoch·학습 웨이퍼를 검사합니다. 일부 웨이퍼를 보류한 폴드 모델은
최종 후보로 읽을 수 없습니다. 새 구성 모델은 전체 개발 자료로 재학습하고, 선택된
기존 모델은 해시를 확인하여 재사용합니다. 저장 후 로더의 예측 확률 일치를 검사합니다.

단일 모델은 logits, 앙상블은 평균 확률의 로그를 반환합니다. 둘 다 `softmax(1)`로
확률을 얻습니다. 임의 가중치나 다른 전처리의 모델 혼합은 허용하지 않습니다.
서버 모델 교체와 웨이퍼 8 재평가는 이 실험에 포함하지 않습니다.

## 로컬 산출물

`plan.json`, `comparison.json`, 설정별 OOF, 폴드별 모델·이력, `candidate.json`,
`result.json`을 새 출력 폴더에만 저장합니다. 실제 영상, 라벨, 예측, 모델은 Git에
추가하지 않습니다. `result.json`에는 기존 모델 유지 여부와 독립 시험 미실시를 기록합니다.

테스트는 오탐·Macro F1 제한에 위배되는 후보의 탈락, 잘못된 웨이퍼·중복 표본·확률
거부, 중간 학습 비중, 앙상블 확률의 저장 전후 일치, 모델 변조 및 폴드 모델 거부를 확인합니다.
